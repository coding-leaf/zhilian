## 1 目标

1. **新增/改动代码有测试锁住**：增量覆盖率达标，且断言真的锁行为（过覆盖率 ≠ 锁行为）。
2. **前端从"无覆盖率"到"有度量"**：先接入工具，再设阈值，避免用错基线。
3. **"通过率 100%"可稳定取证**：正面处理 E-1 墙钟抖动，不放宽阈值。
4. **测试不慢、不依赖外部服务**：沿用"外部能力走协议抽象 + 内存假实现"的既有设计，
   保持全量秒级跑完（依据：`docs/开发过程文档.md` §5.2——测试慢是覆盖率下滑的第一原因）。

---

## 2 覆盖率口径

### 2.1 增量口径（本期准出主线，QG-2 / QG-3）

```
增量覆盖率 = 本次改动中被用例执行到的可执行行数 / 本次改动中的可执行行总数 × 100%

其中「本次改动」= git diff（当前分支 vs origin/master）的新增/修改行；
可执行行 = 排除空行、纯注释、纯文档（.md）后剩余的行。
```

| 适用范围 | 阈值 | 说明 |
| --- | --- | --- |
| 后端：所有改动 | **≥ 80%** | QG-2 |
| 后端：T0 路径（`core/algorithms/`、`core/security.py`、`api/deps/`、`core/errors.py`） | **≥ 90%** | QG-3 |
| 前端：所有改动 | **≥ 80%**（工具接入并观察一个里程碑后启用） | QG-2 |

### 2.2 全量口径（L1 硬门禁，不变）

| 端 | 口径 | 阈值 | 现状 |
| --- | --- | --- | --- |
| 后端 | `app/` 全量、含分支覆盖 | ≥ 80% | 实际 91%+（`Taskfile.yml`） |
| 前端 | 暂无 | 暂无 | 本期接入后观察 |

> **两套口径并存**：全量防倒退、增量防"新代码不测"。增量**叠加**在全量之上，不替换。

### 3.1 后端增量覆盖率（`diff-cover`）


### 3.2 前端覆盖率（先接入，再设阈值）

```bash
cd miniprogram
```

## 5 墙钟抖动处置（E-1）

### 5.1 事实

`backend/tests/unit/core/algorithms/` 下有 **4 处墙钟微基准断言**（200 / 50 / 20 / 100 ms）。
全量套件在 CPU 争用下失败，**单独跑全过**。属既有**测试设计问题**，与具体改动无因果关系。

### 5.2 处置规则（不放宽阈值）

| 场景 | 处理 |
| --- | --- |
| 准出取证 | 用 **§3.3 串行运行**结果作为 QG-1 的通过率证据 |
| 全量并发抖动 | 记为 E-1，**不计为准出阻断项**，但必须进缺陷台账 |
| 复跑确认 | 抖动失败项 `-k` 单独串行复跑，确认通过后附在取证里 |
| **禁止** | ❌ 放宽阈值 ❌ 把抖动当自己引入的回归去追（`AGENTS.md` 定案） |

### 5.3 根治方向（属后续任务）

改为相对基准（如"是否处于同量级"）或标记为性能基准单独跑，**不作为 CI 正确性断言**。
——一个会随机变红的门禁，会让真正的回归淹没在噪音里。

## 6 用例规范

### 6.1 结构与命名

| 项 | 约定 |
| --- | --- |
| 后端位置 | `backend/tests/unit/<层>/test_<模块>.py`（沿用现状目录） |
| 前端位置 | `miniprogram/tests/<主题>.spec.ts`（**平铺，无 `unit/` 子层级**） |
| 用例名 | 被测对象 + 条件 + 期望，例如「未判完时 `loadReport` 返回 `null` 且不发诊断请求」 |
| 结构 | Arrange / Act / Assert 三段；一个用例只断言一个行为 |
| 契约测试 | 后端字段变更时，前端 `fixtures/backendResponses.ts` 同步更新并附后端口径注释 |

### 6.2 断言要求

- **不许"只跑不断言"**：用例必须 `expect/assert` 具体行为，不能只调用函数。
- **不许靠手工补字段让断言通过**：空态/缺失场景应断言真实的 `undefined`/`null`。
- **关键改动做变异验证**（沿用 `docs/开发过程文档.md` §5.3）：
  ≥1 处破坏 → 确认用例失败 → 恢复。**没通过变异验证的用例不算用例**。

### 6.3 反例（写进用例模板的"禁止"）

```python
# ❌ 只执行不断言：覆盖率涨了，行为没锁住
def test_grade():
    grade(answer, rubric)

# ✅ 锁住契约
def test_grade_marks_pending_when_llm_timeout():
    result = grade(answer, rubric)
    assert result.score is None          # 不伪造 0 分
    assert result.status == "pending_regrade"
```
