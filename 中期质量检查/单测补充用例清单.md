## 3 Mock 配置

### 3.1 整体策略

按 `docs/开发过程文档.md` §5.2 与 `tests/conftest.py`：

| 外部依赖 | Mock 方式 | 配置位置 |
| --- | --- | --- |
| LLM | `fake` provider | `tests/conftest.py::offline_default_providers` |
| OCR | `fake` provider | 同上 |
| Embedding | `fake` provider | 同上 |
| Search | `fake` provider | 同上 |
| Storage | `MemoryStorageAdapter` | 同上 |
| Queue | `MemoryQueueAdapter` | `app/integrations/queue/memory.py` |
| Idempotency | `MemoryIdempotencyAdapter` | `app/integrations/idempotency/memory.py` |
| 网络 | `socket.connect` 拦截 | `tests/conftest.py::block_external_network` |
| 真实 DB | SQLite `:memory:` | 测试 fixture `session` |
| 真实 FastAPI 容器 | `app.dependency_overrides[get_*]` | `test_users_router.py` 等 |

### 3.2 新增补测中的 Mock 细节

| 补测模块 | Mock 对象 | 桩化方法 | 验证调用 |
| --- | --- | --- | --- |
| `test_user_deps.py` | `_RecordingContainer`（自建） | `get_session()` / `create_user_service()` | 记录 factory 调用次数 + session 生命周期 |
| `test_user_deps.py` | `_FakeUserService`（自建） | — | isinstance AuthService 协议 |
| `test_user_deps.py` | `_StubSession(Session)`（自建） | `close()` | session.close() 不可由依赖函数触发 |
| `test_user_deps.py` | `MagicMock(spec=Request)` | `app.state.container` | request 路径分支判定 |
| `test_material_repo_filter.py` | 真实 SQLAlchemy Session + 真实 Model | — | E2E SQL 过滤语义 |
| `test_practice_state_machine_supplemental.py` | `MagicMock()` | `practice_repo.*` / `session.*` | 验证 status 拦截与 rollback |
| `test_practice_state_machine_supplemental.py` | 真实 `MemoryIdempotencyAdapter` | — | 强幂等并发锁语义 |

### 3.3 不 Mock 的边界（与纪律一致）

| 类别 | 决策 | 理由 |
| --- | --- | --- |
| 纯算法核 | **不 Mock**，所有输入/输出都是原生 Python 类型 | 纯函数计算核约束（`AGENTS.md` 算法核铁律） |
| 错误类 | **不 Mock**，直接断言 `AppError.__cause__` 链 | 验证 raise from 语义是契约测试的核心 |
| repository 层 | **不 Mock DB**，使用 SQLite 内存数据库 | SQL 谓词与聚合语义必须在真实引擎上验证（防 P1-4 漏算） |
| `MemoryIdempotencyAdapter` | **不 Mock**，直接断言锁行为 | 锁语义本身就是要测试的对象 |
