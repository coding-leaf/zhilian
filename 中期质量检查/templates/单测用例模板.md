### UT-XXX · <用例名：被测对象 + 条件 + 期望>

- **优先级**：P0 / P1 / P2
- **所属模块**：`<模块路径>`

# 后端示例（pytest）

## 填写要点

| 要点 | 说明 |
| --- | --- |
| 一例一断言 | 一个用例只锁一个行为，失败时报错能直接定位 |
| 不断言不写 | 只调用函数而不 `assert/expect` 的用例不计入（覆盖率会涨，行为没锁） |
| 不补字段 | 空态/缺失场景断言真实的 `undefined`/`null`，不靠手工补字段让断言通过 |
| 边界必测 | 空输入 / 极值 / 全错 / 无记录（算法核与鉴权类为必测） |
| 契约同步 | 后端字段变更时，前端 `fixtures/backendResponses.ts` 同批更新并附口径注释 |
| 阈值类改动 | 必须附边界用例与依据（`docs/团队分工.md` §3） |

## 禁止（反例）

```python
# ❌ 只执行不断言
def test_grade():
    grade(answer, rubric)

# ❌ 断言过于宽泛，等于没锁
assert result is not None
```
