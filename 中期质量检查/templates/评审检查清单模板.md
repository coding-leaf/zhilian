# 评审检查清单模板（空白可复用版）

> 用途：空白模板，供**任意一次**代码评审使用。
> 本项目的填好实例见同目录上一级的 `../评审清单.md`（按 T0/T1/T2 已填具体模块）。
> 复制本文件到评审记录目录，逐项打勾后归档。

---

## 评审基本信息

| 项 | 值 |
| --- | --- |
| 评审对象 | <PR 编号 / 分支 / 提交范围> |
| 改动级别 | T0 / T1 / T2 |
| 评审人 | <代号>（T0 需两人，含所有权人） |
| 评审日期 | <YYYY-MM-DD> |
| 关联任务 | <Trellis 任务 / ZL 编号> |

状态标记：`✔ 通过` / `✘ 打回` / `— 不适用（须理由）`
