## 三条纪律（贯穿全部文档）

1. **数字不手抄**：测试规模、覆盖率、提交范围等易变数字只从实时命令取，并附命令与采集日期。
2. **可判定**：每条标准/检查项都能写成「命令 + 期望输出 + 判定人」，拒收不可判定的表述。
3. **不放宽阈值**：抖动的测试是既有设计问题，修问题而不是改测试（`AGENTS.md` 定案）。
