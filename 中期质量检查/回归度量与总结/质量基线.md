### 3.2 门禁执行语义

> **本地跑绿即 CI 跑绿**——CI 命令**精确镜像** `Taskfile.yml::verify-backend`，
> **不另立第二套门禁**。本地通过即 CI 通过。

```yaml
# .github/workflows/verify.yml (摘录)
backend-verify:
  steps:
    - name: ruff format / check
      run: |
        uv run ruff format --check .
        uv run ruff check .
    - name: mypy / lint-imports
      run: |
        uv run mypy app
        uv run lint-imports
    - name: pytest + coverage
      run: |
        uv run pytest tests --cov=app --cov-branch \
          --cov-report=xml --cov-fail-under=80
    - name: T0 核心覆盖率门禁
      run: |
        uv run coverage report \
          --include="app/core/algorithms/*,app/core/security.py,app/core/errors.py" \
          --fail-under=90
    - name: T0 deps 覆盖率门禁
      run: |
        uv run coverage report --include="app/api/deps/*" --fail-under=80
    - name: 增量覆盖率门禁
      run: |
        uv run diff-cover coverage.xml \
          --compare-branch=origin/master --fail-under=80
    - name: 留存测试报告
      uses: actions/upload-artifact@v4
      with:
        name: coverage-report
        path: coverage.xml
        retention-days: 14
```

### 3.3 分支保护规则

> **GitHub 分支保护**：「Require status check before merging」必须勾选下列 check：

| 必须 check | 说明 |
| --- | --- |
| `verify-backend / ruff-format-check` | ruff format |
| `verify-backend / ruff-lint-check` | ruff check |
| `verify-backend / mypy-check` | mypy |
| `verify-backend / lint-imports-check` | import-linter |
| `verify-backend / pytest-cov` | pytest + 全量覆盖率 |
| `verify-backend / t0-core-cov` | T0 核心覆盖率 |
| `verify-backend / t0-deps-cov` | T0 deps 覆盖率 |
| `verify-backend / diff-cover` | 增量覆盖率 |

> **PR 模板要求**：至少 1-2 人评审（关键模块 2 人），任何机器门禁不绿 → 禁止合并。

## 4 评审基线

### 4.1 评审结论分档

| 结论 | 含义 | 触发 |
| --- | --- | --- |
| ✅ 通过 | 0 阻塞 / 0 重要 | PR 可合并 |
| 🟡 修改后通过 | 仅 🟡 建议或 0 阻塞 + 少量可同 PR 修的重要 | 修改后复核 |
| ❌ 不通过 | 有 🔴 阻塞 | 必须重写或拆分 |

### 4.2 问题分级统计基线

| 项 | 中期实测 | 基线 |
| --- | ---: | ---: |
| 🔴 阻塞 | 3/3 闭环 | 0 个为最佳（任何阻塞即视为质量风险） |
| 🟠 重要 | 9/9 闭环 | < 5% 为最佳 |
| 🟡 建议 | 4 微调 + 12 登记 | 0 个为理想，但可登记 M1 池 |
| 产品代码 bug | 3/3 修复 | 任何 1 个都触发「评审人眼检异常」 |
