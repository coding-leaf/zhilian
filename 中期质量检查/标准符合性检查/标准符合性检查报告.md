## 4 数据事故：覆盖率口径失真（本检查的重要发现）

### 4.1 事故经过

| 时间 | 事件 |
| --- | --- |
| 10-04 17:43 | 全量 `pytest tests --cov=app --cov-branch` 运行，归档数据 **91%**（12697/803/3602/434）→ `coverage_total.txt` |
| 10-04 17:43~18:00 | 期间执行多次**局部**覆盖率运行（`--cov=app.xxx` 子集），`.coverage` 数据文件被覆盖为子集（2520 stmts） |
| 10-04 18:00 | 报告撰写时运行 `coverage report --fail-under=80`，读到**残留子集数据** → 误记为「全量 98%、T0 deps 90%」 |
| 10-04 19:23 | 标准符合性检查复核：发现与归档文件矛盾 → 重跑全量 → 权威数据 **91% / 84%** |

### 4.2 根因

1. **coverage 数据文件单例**：`.coverage` 是单文件，局部运行会**覆盖**全局运行的数据，无「合并/隔离」机制；
2. **报告数字未附命令与范围**：抄录时未记录「本次 report 对应的 run 范围」，无法自证口径；
3. **与项目历史坑 E-2 同源**：「覆盖率会骗人」（`docs/后续待解决问题.md`）——**已预知的问题再次发生**。
