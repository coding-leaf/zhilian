# PR Review Gate (代码审查与门禁执行)

本技能指导主会话或审查角色依据根目录 `REVIEW.md` 执行标准化审查与准入把关。

## 1. 审查前置依据 (Prerequisites)
审查开始前，必须明确本次审查的输入凭据，严禁脱离证据泛化评价：
- **代码变动 Diff**：`git diff` 或 PR 文件列表；
- **任务契约工件**：对应 Task ID 及其 `spec.md`（技术契约）与 `plan.md`（实施范围）；
- **真实验证证据**：终端实际执行的构建与测试命令输出。

## 2. 审查规范与判定规则 (SSOT: REVIEW.md)
所有审查维度、阻断级别与建议控制**严格以根目录 `REVIEW.md` 为唯一事实源**：
- **Pass 1: 缺陷与逻辑正确性**（边界空值、并发安全、资源释放、协议契约）；
- **Pass 2: 安全性与隔离防护**（权限鉴权、敏感凭证禁硬编码、日志脱敏）；
- **Pass 3: 契约一致性与 KISS 规范**（核对范围防超纲扩围、KISS 架构底线排查）；
- **判定与熔断**：阻断合并项（Critical / Important）必须归零；次要建议（Nit）**严格熔断上限 5 条**。

## 3. 输出结构
向主会话输出简洁、结构化的审查报告：
- **审查结论**：`[PASS - 批准放行]` 或 `[BLOCK - 存在阻断缺陷]`；
- **缺陷列表 (若有)**：按维度列出严重级别、`filepath:line`、违规描述与修复建议；
- **验证结论**：若无阻断缺陷且测试全绿，明确给出放行结论。
