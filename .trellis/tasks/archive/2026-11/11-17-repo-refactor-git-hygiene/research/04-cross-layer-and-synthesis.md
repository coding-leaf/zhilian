### 1.2 DTO/Schema ↔ Frontend Type & Adapter Drift

1. **P0 — Silent Payload Drift in Knowledge Tree & Snippet Traceability (`course/index.vue` Always Shows "第 1 页" & Dead `key_phrases`)**:
   - **Backend anchors**:
     - `SnippetSourceResponse` (`backend/app/schemas/knowledge.py:66-78`) returns `{ id, material_id, version_id, page_index, snippet_index, chapter_title, content, char_length }`. It has **no** `page_number`, **no** `similarity`, and **no** `section_title`.
     - `KnowledgeTreeNodeResponse` (`backend/app/schemas/knowledge.py:16-32`) returns `{ id, material_id, version_id, parent_id, name, description, level, is_low_confidence, children }`. It has **no** `order_index` or `key_phrases`.
     - `KnowledgePointDetailResponse` (`backend/app/schemas/knowledge.py:48-63`) returns `{ ..., batch_id, created_at, updated_at }`. It has **no** `order_index`, `key_phrases`, or `snippet_count`.
   - **Frontend anchors**:
     - `miniprogram/src/types/index.ts:109-150` defines `KnowledgeTreeNode` (`order_index`, `key_phrases?`, missing `is_low_confidence`), `KnowledgePointDetail` (`order_index`, `key_phrases?`, `snippet_count?`), and `KnowledgeSnippet` (`page_number?`, `similarity?`, `section_title?`, missing `page_index`, `chapter_title`).
     - `miniprogram/src/subpackages/material/pages/course/index.vue:73-77` renders `v-if="node.key_phrases && node.key_phrases.length"` (permanently dead UI).
     - `miniprogram/src/subpackages/material/pages/course/index.vue:132-133` renders `第 {{ snip.page_number || '1' }} 页` and `v-if="snip.similarity"` — in production `snip.page_number` is always `undefined`, so **every source snippet silently displays "第 1 页"** instead of `snip.page_index`, and similarity never displays!
