# 全新前端架构与用户体验重构 PRD

## Goal

彻底替换旧前端混乱脆弱的代码结构，从零构建清晰、稳定、美观的全新 Uni-App + Vue 3 + TypeScript 移动学习端，打通 J1~J8 全流程垂直闭环，并融入“深度解析（追问 AI 助教）”与“极致离线防丢/断点容灾”两大核心体验增强特性。

## Requirements

### 1. 全局底座与导航架构
- 采用原生底部三 Tab 规范底座：
  - **Tab 1: 学习工作台 (pages/index/index)**：课程分类、最近未完成练习恢复入口、多格式/多图快速导入出题入口。
  - **Tab 2: 学情与错题 (pages/review/index)**：掌握度总览概貌、薄弱知识点雷达、错题攻克看板与多维筛选重练。
  - **Tab 3: 我的与数据安全 (pages/profile/index)**：学习资产总览、隐私承诺与数据治理专区（归档管理、物理注销与数据抹除）。

### 2. J1~J3 导入、多页 OCR 质检与出题核验流
- **多图选择与格式支持 (J1/J2)**：支持拍照与相册单次批量选择（最多 9 张），支持微信聊天文件导入与本地常见格式（PDF、DOCX、PPTX、TXT、MD）。
- **画廊式 OCR 质检与单页重拍 (J2)**：以缩略图网格清晰展示每页状态（合格/模糊/缺角），异常页高亮并支持单页即时重拍或替换，底栏展示合格率，合格即可流转下一步。
- **题目生成与质检核对清单 (J3)**：出题过程异步轮询与状态化展示；生成后在进入作答前提供核验清单，可展开讲义原文引文出处、查看 AI 质检建议，支持手动修改或删除不合格题目。

### 3. J4 沉浸式练习作答与离线容灾
- **作答界面交互**：顶部题量进度，卡片左右滑屏切题，底部悬浮答题卡抽屉（标清已答、未答、标记疑问），交卷时智能拦阻并提示未作答题数。
- **断点防丢引擎 (UX 增强)**：答案选定/输入毫秒级双轨持久化（本地 Storage 缓存 + 后端防抖同步）；意外退出、切后台、断网恢复后无感秒级断点续答；重复点击交卷幂等拦截。

### 4. J5~J6 判题解释、纠偏与薄弱点定向强化
- **分步动效过渡与后台生成**：提交后展示客观题核验 -> 主观题采分比对 -> 诊断画像构建的三阶段轻动效，支持超过阈值后静默后台生成并安全回退。
- **多维采分对齐与双通道纠偏 (J5)**：主观题展示得分依据、命中/遗漏采分点及对应讲义原文引文；提供【AI 复核】与【信任自评覆盖】双通道，历史日志如实记录自评状态。
- **定向攻克薄弱点 (J6)**：诊断报告直接提炼薄弱知识点，支持“一键强化练习”，请求精准绑定薄弱知识点范围与 source_report_id。

### 5. J7 错题本看板与多选组卷
- **攻克看板与筛选**：按课程、题型、时间段筛选错题，展示掌握进度环；支持单题温习与多选勾选（错题购物车）组合专属试卷；答对后自动归档至“已攻克”，历史数据永续留痕。

### 6. J8 课程治理与数据安全掌控
- **课程整理与归档**：支持未分类资料整理至独立课程文件夹，课程支持归档与一键恢复。
- **隐私与物理注销**：提供明确的数据使用与加密说明，提供高安全级别的账户注销与数据彻底擦除能力（带二次确认及物理删除路由绑定）。

### 7. 深度解析 AI 助教 (UX 增强)
- 在题目解析与错题详情中，提供【追问 AI 助教】抽屉式对话，允许学生针对不理解的采分点或概念进行追问解惑。

### 8. 全栈协同支持要求
- **后端支持指定题目 ID 组卷 (J7 错题针对性重练)**：在 `POST /api/v1/practices` 与 `PracticeCreateRequest` 中支持可选入参 `question_ids: list[uuid.UUID]`，允许前端错题本勾选指定 N 道题目直接组卷。
- **后端支持 AI 助教答疑 (UX 增强)**：新增轻量接口 `POST /api/v1/questions/{id}/ask-coach`，支持结合当前题目上下文、采分点与用户追问内容返回通俗易懂的 AI 解答。

## Acceptance Criteria

- [x] **A1 (导航底座)**：小程序启动后展示标准的“学习”、“学情/错题”、“我的”三 Tab 架构，页面切换平滑且生命周期管理清晰。
- [x] **A2 (J1 最薄闭环)**：从导入文件/图片 -> 出题核验 -> 练习作答 -> 提交试卷 -> 报告生成并展示，全流程无缝跑通无任何死链接。
- [x] **A3 (J2 OCR质检)**：一次选择多张图片时，网格画廊能准确标识不合格页，支持单页重拍并替换，无需重传整套图片。
- [x] **A4 (J3 题目质检)**：出题结果展示来源引文与质检标签，用户可编辑题目内容或删除题目后直接点击开始作答。
- [x] **A5 (J4 离线容灾)**：作答过程中杀死小程序或离线，重新进入后能精准恢复已填写的各题选项与草稿，交卷前有未答数二次拦截。
- [x] **A6 (J5 采分与自评)**：主观题详情展示命中/遗漏要点；点击自评打分能即时更新本题状态并提交后端判题记录。
- [x] **A7 (J6/J7 错题重练)**：诊断报告的“强化练习”仅包含薄弱点；错题本能多选特定错题并成功生成针对性练习。
- [x] **A8 (J8 隐私与注销)**：个人中心能查看学习资产、管理归档课程，并提供符合安全流程的账号注销物理擦除。
- [x] **A9 (全栈协同接口与测试)**：后端新增的指定题目组卷与 AI 助教答疑接口具备完整测试与类型契约；前端完整对接。
- [x] **A10 (代码质量与编译)**：全新前端代码结构干净规范，通过 `npm run type-check` 与 `npm run lint`，后端通过 `pytest`。
