## 1. 问题与现状背景 (Problem)
在智练学习平台的出题主链中，系统利用检索增强技术（RAG）为知识点检索相关片段，并驱动大语言模型（LLM）自动生成题目（FR-20~23）。
然而，生成式大模型在批量出题时，容易产生以下四类典型的数据与业务质量缺陷：
1. **无来源题目（幻觉脱靶）**：大模型根据预训练泛化知识脱离资料原文自由发挥，生成的题目在资料切片中无法溯源，或实词重合率极低（$< 30\%$）；
2. **重复题（题库冗余）**：与同资料下已有题目语义高度雷同（向量相似度 $> 0.90$ 或字符相似度 $> 0.85$），或在同一生成批次内题干完全重复；
3. **答案冲突（知识打架）**：针对高度相似的客观题干（相似度 $> 0.88$），大模型给出了完全不同甚至相反的标准答案，导致用户在练习时产生严重困惑；
4. **明显歧义（逻辑不自洽）**：单选题存在多个正确选项、多选题正确选项包含全量选项或少于 2 项、判断题非二值答案、填空题空答案、选项重复、题干过短（$< 6$ 字符）或出现“以上都对/错”与独立选项冲突。

需求规范（FR-24、FR-25、FR-28）与概要设计说明书（第 6.4 节）明确规定：
所有生成的候选题目必须经过后台纯函数题目质检门禁（`filter_qualified_questions`），严格按照**无来源**、**重复题**、**答案冲突**、**明显歧义**的固定顺序执行四类检查。任意一项不通过即被拦截进入待处理区（`pending_review`），严禁流入练习组卷与掌握度诊断统计。

当前系统已在 `ZL-105` 中定义了 `Question`、`QuestionQualityCheck` 实体与 `QualityCheckType` 枚举，但缺乏底层的**纯函数题目质检与待处理过滤算法计算核 (`filter_qualified_questions`)**。

## 3. 期望达成效果 (Proposed Outcome)
1. 在 `backend/app/core/algorithms/question_quality.py` 中实现 `filter_qualified_questions` 纯函数及其辅助核；
2. 严格对齐《概要设计说明书》第 6.4 节与《软件需求规格说明书》FR-24、FR-25、FR-28 规范：
   - **四类一票否决固定执行顺序**：`NO_SOURCE` -> `DUPLICATE` -> `ANSWER_CONFLICT` -> `AMBIGUITY`，命中多个时取最靠前的一项；
   - a. **无来源检查 (`check_source_grounding`)**：
     - 来源片段标识缺失，或指向的片段内容为空；
     - 来源片段存在，但题干中实词（长度 $\ge 2$ 的中文词或英文词）在片段中的出现比例 $< 30\%$ ($0.30$)；
   - b. **重复题检查 (`check_duplication`)**：
     - 候选题目与同资料已有题目（最近 500 道）的向量余弦相似度 $\ge 0.90$ 或字符相似度 $\ge 0.85$；
     - 同一批次内同一题干出现多次时，保留时间最早的一道，其余判为重复题；
   - c. **答案冲突检查 (`check_answer_conflict`)**：
     - 仅对客观题生效（主观题跳过该项）；
     - 题干相似度 $\ge 0.88$ 的已有客观题之间，比对标准答案集合；若标准答案不一致（无序集合比较），判为答案冲突；
   - d. **明显歧义检查 (`check_ambiguity`)**：
     - 题干字符长度 $< 6$ 判为歧义；
     - 单选题正确项数 $\ne 1$；多选题正确项数 $< 2$ 或等于全量选项数；判断题答案非二值；填空题答案为空；
     - 选项集合中存在重复选项内容；
     - 题干或选项中出现“以上都对/都不对”且同时存在其它正确选项；
   - **5 大边界条件严格闭环**：
     - 候选题为空集合：返回空列表，不报错；
     - 批次内同题干重复：保留首发题，其余标记重复；
     - 来源片段内容为空：按无来源处理；
     - 向量不可用时：优雅降级为文本相似度计算，并在报告中标注降级状态；
     - 相似度恰好等于阈值（如 0.90, 0.85, 0.88）：按触发拦截处理（开闭区间：闭区间 $\ge$ 阈值）；
     - 阈值配置合法性校验：非空且 $0 \le threshold \le 1$，非法时抛出 `ValueError`。
3. 单元测试用例全矩阵覆盖，判定覆盖率达到 100%（条件组合覆盖 MCC），行覆盖率 $\ge 95\%$，分支覆盖率 $\ge 90\%$，复杂度 $V(G) \le 8$。
