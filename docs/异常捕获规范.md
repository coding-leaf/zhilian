## 1 总则

> **捕获具体异常**而非「**Exception**」。
> 「**让错误暴露**」优于「**宽捕获**」。

---

## 2 三大铁律

### 2.1 必须捕获具体异常类型

```python
# ✅ 正确
try:
    task_id = self.queue.enqueue(...)
except QueueError:
    self.session.rollback()
    raise

# ❌ 错误
try:
    ...
except Exception:
    self.session.rollback()
    raise
```

### 2.2 必须保留异常原因链

```python
# ✅ 正确：用 raise X from exc 保留原因
except (QueueError, SQLAlchemyError) as exc:
    self.session.rollback()
    raise PracticeStatusError(...) from exc

# ❌ 错误：丢失原始异常
except (QueueError, SQLAlchemyError):
    raise PracticeStatusError(...)  # 原因链断裂
```

### 2.3 必须有针对性的清理动作

```python
# ✅ 正确：清理动作与具体异常关联
except (QueueError, SQLAlchemyError):
    self.session.rollback()  # 数据库异常需要 rollback
    raise

# ❌ 错误：清理动作与异常类型无关联
except Exception:
    self.queue.enqueue()  # 这是为什么？
    raise
```

## 5 不推荐的捕获（CI 规则禁止）

### 5.1 `except Exception`（顶层兜底除外）

```python
# ❌ 禁止
try:
    ...
except Exception:
    self.session.rollback()
    raise

# ⚠️ 例外：顶层兜底（必须有注释）
except Exception:  # noqa: BLE001 - 顶层兜底
    logger.exception("unhandled error")
    raise InternalServerError(...)
```

### 5.2 `except`（裸捕获）

```python
# ❌ 禁止：捕获所有（包括 BaseException）
try:
    ...
except:
    ...
```

### 5.3 捕获 `BaseException`

```python
# ❌ 禁止
try:
    ...
except BaseException:
    ...
```

### 5.4 捕获 `KeyboardInterrupt` / `SystemExit`

```python
# ❌ 禁止
try:
    ...
except KeyboardInterrupt:
    ...
```

## 7 测试断言配套

### 7.1 `pytest.raises` 必须具体

```python
# ✅ 正确
with pytest.raises(QueueError) as exc_info:
    queue.enqueue(...)
assert exc_info.value.error_code == 30015

# ❌ 错误
with pytest.raises(Exception):
    queue.enqueue(...)
```

### 7.2 原因链断言

```python
# ✅ 正确
with pytest.raises(PracticeStatusError) as exc_info:
    service.retry_grading(...)
# __cause__ 链必须保留
assert isinstance(exc_info.value.__cause__, QueueError)
```

## 9 修复案例：`except Exception` → `except (QueueError, SQLAlchemyError)`

**修复前（评审 🟠 重要 / BUG-03）**：
```python
try:
    ...
    task_id = self.queue.enqueue(...)
    self.session.commit()
except Exception:
    # 入队失败必须回滚状态
    self.session.rollback()
    raise
```

**修复后**：
```python
try:
    ...
    task_id = self.queue.enqueue(...)
    self.session.commit()
except (QueueError, SQLAlchemyError) as exc:
    # BUG-FIX: 之前 except Exception 太宽，会吞掉 KeyboardInterrupt 等
    self.session.rollback()
    raise PracticeStatusError(
        "判题任务入队失败，请稍后重试",
        details={"reason": str(exc), "original_type": type(exc).__name__},
    ) from exc
except PracticeStatusError:
    # 并发冲突不需要包装，原始错误向上抛
    self.session.rollback()
    raise
```

**评审复评结论**：✅ 通过
